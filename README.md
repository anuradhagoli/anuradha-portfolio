# Anuradha Goli — Executive Portfolio Website

A responsive static portfolio website designed for GitHub Pages.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current footer year

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `anuradha-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub Pages to deploy. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/anuradha-portfolio/`.

To use the account-level address `https://YOUR-GITHUB-USERNAME.github.io/`, name the repository exactly `YOUR-GITHUB-USERNAME.github.io`.

## Before publishing
- Review every role, date, achievement and qualification for accuracy.
- The Salesforce dates are set to February 2024–October 2025, as confirmed.
- DCU is not included.
- The email address is linked but not printed as plain text; the phone number is not published.
- The LinkedIn link points to the profile supplied by Anuradha. Add direct links to individual LinkedIn posts if desired.
- Google Fonts are loaded from Google Fonts; the site otherwise uses static HTML, CSS and JavaScript with no build step.

## Edit content
Open `index.html` in any text editor. Update the relevant text and commit the changes to GitHub; Pages will redeploy automatically.
